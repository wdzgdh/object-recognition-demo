# 数据准备目录

本目录用于存放课程作业要求的图片数据（目录仅供参考，程序录入图片不依赖这里的结构）。

## 目录说明

- `register/` — 注册用图片（按物体分文件夹，≥5 个物体，每个 ≥5 张）
  ```
  register/
    cup/       # 水杯
    bottle/    # 瓶子
    book/      # 书
    phone/     # 手机
    keyboard/  # 键盘
  ```
- `test/` — 测试用图片（与注册图不重复）
- `unknown/` — 未知物体测试图（≥3 个未录入物体）

## 课程硬性要求

1. 至少 5 个物体，每个物体 ≥5 张图片
2. 注册图片与测试图片不要完全相同
3. 至少 3 个未录入的物体，用于测试"未知物体"判断

## 提示

这些图片是你自己准备后，通过程序界面「录入」Tab 添加的。
你也可以直接把图片放到 `register/` 下按物体分好文件夹，便于管理。
